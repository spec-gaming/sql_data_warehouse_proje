# sql_data_warehouse_proje
creating a mordern a modern data warehouse using sql, including ETL process, data modelling and analytics. From building a data warehouse project to generating actionable insights.
This is designed as a portfolio project, highlighting industry best standards and practices in data engineering and analytics.


## Project Requiremnents

### Building the Data wareHouse

#### Objective
Develop a modern data warehosue using sql server to consolidate sales data, enabling analytical reporting and informed decision-making.

#### Specification
- **Data Sources**: import data from two source systems (ERP and CRM) provided as CSV files.
- **Data Qality**: Clean and resolve data qualiity issues prior to analysis.
- **Integration**: Combine both sources into a single, suer-friendly data model designed for analytical queries.
- **Scope**: Focus on the latest dataset only. Historization of data is not required.
- **Documentation**: provide clear communication of the data model to support both business stakeholders and analytics teams.
